# Bi-Color LED with Arduino

## Purpose
Control a bi-color LED (Red and Green) using an Arduino Uno.

## Components
- Arduino Uno
- Bi-Color LED
- 2 × 220Ω Resistors
- Jumper Wires

## Connections
- Red Pin → D11 (through 220Ω resistor)
- Green Pin → D10 (through 220Ω resistor)
- Cathode/Common Pin → GND

## Working
1. Arduino turns the Red LED ON for 1 second.
2. Arduino turns the Green LED ON for 1 second.
3. Both LEDs turn ON together for 1 second.
4. The cycle repeats continuously.

## Output
- Red Light
- Green Light
- Yellow Light (Red + Green)
