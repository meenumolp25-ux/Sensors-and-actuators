# 7-Segment Display with Arduino

## Purpose
Display numbers using a 7-segment display.

## Components
- Arduino Uno
- 7-Segment Display
- 7 × 220Ω Resistors
- Jumper Wires

## Connections
a → D2
b → D3
c → D4
d → D5
e → D6
f → D7
g → D8
Common Cathode → GND

## Working
Arduino controls each segment to display a number. In this project, the display shows the digit 0.

## Output
0
