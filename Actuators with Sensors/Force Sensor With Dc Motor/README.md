# Force Sensor Controlled DC Motor

## Description
This project controls a DC motor using a force sensor.

## Working
- Force sensor detects pressure.
- Arduino reads the force value from A0.
- If pressure is applied, the motor turns ON.
- If no pressure is applied, the motor turns OFF.

## Output
Force Applied → Motor ON  
No Force → Motor OFF

## Applications
- Pressure switches
- Smart controls
- Automation projects
