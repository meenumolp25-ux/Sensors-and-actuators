# Analog Sensor Controlled LED

## Description
This project reads an analog sensor value and controls an LED based on the sensor output.

## Working
- Sensor gives an analog voltage through Vout.
- Arduino reads the value from A0.
- When the sensor value crosses the limit, LED turns ON.
- Otherwise LED remains OFF.

## Output
High sensor value → LED ON  
Low sensor value → LED OFF

## Applications
- Sensor indicators
- Automatic control systems
- Monitoring projects
- Arduino experiments
