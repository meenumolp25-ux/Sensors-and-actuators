# Flex Sensor with Arduino

## Purpose
Measure the bending of a flex sensor.

## Connections
- Flex Sensor Pin 1 → 5V
- Flex Sensor Pin 2 → A0
- 10kΩ Resistor → A0 to GND

## Working
The flex sensor changes resistance when bent. Arduino reads the value and displays it on the Serial Monitor.

## Output
Flex Value: 520
